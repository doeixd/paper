**IIT's core question in Rosas language:** Given a system with ε-machine $M$, can $M$ be factored into independent sub-ε-machines $M_A$ and $M_B$ for any partition of the system into parts $A$ and $B$? Causal Closure (Rosas) says: the macro doesn't need the micro. Integration (IIT) says: the whole can't be split into parts. One is about levels being self-sufficient.
