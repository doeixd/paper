# Summary of edits

Verified the recent panpsychism-paper additions against stable sources and made a narrow prose cleanup before rebuilding.

Changes made:

- Added the quality/role distinction to the introduction so the paper's core target is clearer: acquaintance may reveal phenomenal character, but it does not by itself reveal a categorical-grounding, microphysical, cosmic, or fundamental role.
- Defined the target as first-person-motivated panpsychism, which protects purely theoretical panpsychist arguments from being treated as the paper's main target.
- Reduced combination-problem material so combination now functions as downstream theoretical machinery rather than the paper's central objection.
- Added a short transparency-of-experience paragraph, supported by Dretske and Tye, to anchor the claim that introspection does not disclose metaphysical status merely by disclosing phenomenal character.
- Moved the Schwitzgebel caution earlier in the paper, where it supports the limits of introspection rather than appearing as a late new issue.
- Added a concise cosmopsychism reply that anticipates localization, partition, or dissociation responses while preserving the central point: the cosmic subject as cosmic is not introspected.
- Strengthened the Mørch/phenomenal-powers discussion by granting felt agency, motivation, effort, and efficacy while distinguishing those macro-psychological phenomena from stripped-down fundamental causal powers.
- Shortened the conclusion and varied repeated "hidden phenomenal ontology" phrasing where possible.

Verification:

- Checked MIT Press pages for Fred Dretske's *Naturalizing the Mind* and Michael Tye's *Consciousness, Color, and Content*. The bibliographic details and ISBNs used in the paper match the listed hardcover editions.
- Checked PhilArchive/Topoi metadata for Mørch's "Does Dispositionalism Entail Panpsychism?" The abstract supports the paper's description of the relevant premise about phenomenal properties, categorical grounds, agency, intention, and motivation.
- Checked a Kastrup source for the dissociation/alter style of response. The paper did not add a Kastrup citation, because the prose only needs to anticipate a general cosmopsychist/idealist reply and the existing cosmopsychism references already support the local dialectical context.

Build:

- Rebuilt `overdrawing-on-experience-sn.tex` with `pdflatex -> bibtex -> pdflatex -> pdflatex`.
- Copied the compiled PDF to `pan/overdrawing-on-experience-sn.pdf`.
- Checked the LaTeX log for undefined citations or references. None were found.

Rationale:

The edits are intended to improve target precision without changing the paper's burden. They make the paper less vulnerable to the charge that it attacks panpsychism as such, overstates the combination problem, or ignores sophisticated replies from cosmopsychists and phenomenal-powers views. The added sources support only modest claims, and the prose avoids leaning on them for more than they establish.
